ZomoReels — Reel-Based Food Discovery

A full-stack food discovery platform inspired by Zomato, where restaurants upload short-form food reels and users browse a TikTok-style fullscreen vertical video feed. The app supports two completely separate roles — Users and Food Partners — each with their own authenticated dashboard, profile, and feature set. Deployed on Vercel (frontend) and Render (backend) with MongoDB Atlas as the cloud database.

Key Features

  • Dual-role auth (User & Food Partner) using JWT in HttpOnly cookies — XSS-safe, 7-day expiry with synced cookie lifecycle
  • TikTok-style scroll-snap vertical video feed with autoplay, mute toggle, and smooth reel transitions
  • Full media pipeline — Multer (in-memory) → base64 → ImageKit CDN → URL stored in MongoDB
  • Like / save system with optimistic UI updates and atomic DB count sync via Mongoose
  • Zod schema validation on every POST endpoint via a reusable middleware factory
  • Public restaurant profile pages, saved reels tab, food partner dashboard with avatar management
  • Fully responsive — desktop, tablet, and mobile with dark mode support

Tech Stack

React 19 Vite Node.js Express.js MongoDB Mongoose JWT bcrypt Multer ImageKit Zod
