Spotify Like Audio Player

A fully responsive Spotify-inspired music player built from scratch. The app features real audio streaming, playlist management, and a smooth music playback interface designed for all screen sizes. Users can browse songs, manage playlists, and control playback in real-time — all from the browser.

Key Features

  • Full audio playback with play/pause, seek, and volume control
  • Dynamic song listing fetched via a Node.js + Express.js backend
  • Playlist and queue management built with vanilla JavaScript
  • Fully responsive layout — works on both desktop and mobile
  • Animated progress bar synced to real-time track position

Tech Stack

HTML5 CSS3 JavaScript Node.js Express.js
